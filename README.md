# チェンソーマン頭（Chainsaw Man Head）

チェンソーマンの頭部コスプレ製作プロジェクトです。Arduinoのソースコード、配線図、3Dプリント用STLファイルなどを無料で公開しています。

## 内容

- `src/` — Arduinoソースコード
- `wiring/` — 配線図（準備中）
- `stl/` — 3Dデータ一式（`本番部品/` に部位別のSTL 127点、`図面/` に図面PDF 7点）
